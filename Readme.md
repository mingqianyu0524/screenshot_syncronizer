#Readme

##QuickStart

###Server side
1. activate venv

2. run server:
`python main.py`
   
3. or run silently:
`./run_silent.sh`
   
4. finish:
`./kill_script.sh`
   
###Client side
####home

1. Find out your mac's ip address: `ipconfig getifaddr en0`

2. iphone browser visit:`http://<ip-addr>:5050`

####hotspot
1. Find your mac hostname in settings-sharing-hostname, such as MacBook-Pro.local

2. iphone browser visit:`http://<your-host-name>:5050`
